本轮目标：将听写工具升级为个人备考工作台，保留全部 5873 条原始记录、原有本地数据与单 HTML 使用方式。

已对齐的需求：

1. 白天采用暖白与墨绿；黑夜采用深灰与低亮度墨绿，支持跟随系统并记忆选择。
2. 背词有“看词回忆中文”和“听音回忆拼写与中文”两种方式；两个方式均可选全部词、错词或到期词。揭晓前不显示答案，独立记录掌握情况。
3. 听写支持章节、乱序、范围与分段；音频按顺序继续、输入不自动换行。播放支持暂停、继续、重播与进度。
4. 错词保留来源、原始错拼、原因与复习历史；掌握后不再列入当前到期队列，历史仍保留。
5. 每日复习、个人目标、首次与订正成绩、个人词表、草稿恢复、完整备份与旧版迁移。
6. 本地原录音精听、A–B 循环、变速、片段听写，以及数字、日期、姓名、地址、短语、句子填空与同义替换专项。

开发阶段与独立提交：

- 词库、批改、会话、存储与迁移的模块化和回归检查。
- 完整播放控制与听写、草稿、备份交互。
- 两种背词、跨日复习、错词原因与个人词表。
- 本地精听、专项练习、个人目标与复盘。
- 日夜主题、响应式排版、真实页面验证、文档和发布产物核对。

验收要求：每阶段有对应验证；既有记录不删除；重复提交不重复计错；首次成绩不被订正覆盖；文件打开和静态部署使用同一套产物。仅作本地 Git 提交，推送和部署另行记录状态。
