# 词间 · 王陆听力工作台

一个在浏览器里使用的个人备考工具：看词、听音、听写，再按掌握情况复习。暖白与墨绿的白天主题，以及适合晚间学习的黑夜主题。

![白天主题](docs/screenshots/home-light.jpg)

![黑夜主题](docs/screenshots/home-dark.jpg)

截图中的记录为开发验收样例；发布文件不预置个人练习历史。

## 使用

直接用 Chrome 或 Edge 打开 `index.html` 或 `王陆语料库听写练习_v5.html`。两者由同一份源代码生成，功能一致，不需要安装运行时依赖。网页与词库可以本地打开，发音是否离线可用取决于系统英语语音包；在线词典与合成语音需要网络。

建议固定使用同一个文件或站点地址。不同浏览器、设备、域名，以及部分浏览器的不同本地文件之间，存储可能隔离；转移前请导出备份。

## 功能

| 功能 | 用法 |
| --- | --- |
| 看词回忆 | 看英文，回忆中文后揭晓，标记认识、模糊或不会 |
| 听音回忆 | 先隐藏英文和中文，听音回忆拼写与词义；可输入拼写自测，播放后揭晓 |
| 听写 | 顺序或乱序；20 / 50 / 100 词、全部或自选位置范围；批改与完成分开 |
| 播放 | 连播不移动输入光标；暂停、继续、上一词、下一词和重播；失败停留在当前词 |
| 词库选择 | 全部词、错词、当前模式到期词、个人词表、听力专项 |
| 错词本 | 章节、方式、掌握状态、错因与搜索筛选；原始错拼链与来源保留 |
| 每日复习 | 看词、听音、听写分别记录；跨日复测；首页显示到期词、今日词量与专注时间 |
| 成绩 | 首次与订正成绩分别保留；趋势仅比较相同题集和设置；错词复练也保存历史 |
| 精听室 | 选择本地录音，标记 A–B 片段、循环、变速、保存听写和参考原文；订正保留首次文本 |
| 专项 | 数字、日期、姓名、地址、词尾、短语、句子填空、同义替换，共 8 类自编练习 |
| 数据 | 自动保存练习草稿、恢复原题序、完整 JSON 备份、预览合并或替换、旧版迁移 |
| 外观 | 白天、黑夜、跟随系统；手机与桌面布局；键盘操作 |

### 键盘

- 听写：`Enter` 下一行；`F2` 播放当前输入行；`Ctrl/⌘ + Enter` 批改。
- 背词：`空格` 揭晓；`1` 认识、`2` 模糊、`3` 不会。正在输入时不拦截这些按键。
- `Escape` 关闭详情并暂停听写队列。

### 数据与复习规则

- 原始词库共有 **4 个大章、32 个练习单元、5873 条记录**。原文存于 `data/vocab.json`，保留章节重复词；答案别名、朗读文本与释义分开处理。
- 旧版 `wl3_hist / wl3_wb`（以及 `wl2` 历史和错词）会迁移到新版 `wl4_workspace`，旧键值不删除。其他浏览器的旧数据可在设置中粘贴 `{"hist":{...},"wb":{...}}` 导入。
- 批改只冻结首次结果与显示反馈；完成时一次记账。重复完成不重复累计错误。订正不覆盖首次表现。
- 错词按词项聚合并保留来源；同词不同词义可分别记录。不同模式分别安排复习。默认间隔为 1、3、7、14、30、60 天，跨日连续 3 次首次回忆正确标为已掌握；这是可解释的初始规则，不是个人最佳间隔的测量结果。
- 音频失败后，可重试或明确标记“未播放”跳过。未播放项不进入成绩分母与错误次数。
- 浏览器空间不足会提示保存失败，保留当前练习以供重试；不同页面同时修改数据时会提示冲突。
- 备份包括文字记录、词表、草稿、设置和录音片段标记，**不包含录音文件**。音频尝试缓存到本机 IndexedDB；缓存不可用时重新选择原文件即可使用。
- 语料 TTS 和自编专项用于训练，成绩不换算雅思听力分数；专项并非官方试题。

## 开发

需要 Node.js 22 或更新版本：

```sh
npm ci
npm run dev
```

打开终端显示的 `http://127.0.0.1:4173`。修改源文件后重新运行 `npm run build` 并刷新网页。开发服务器仅监听本机地址。

```sh
npm test          # 领域逻辑和 DOM 交互检查
npm run build    # 生成两个独立 HTML，均不依赖 CDN 字体或运行时脚本
npm run check    # 测试、构建、独立文件一致性和脚本语法验证
```

源码位置：

```text
data/vocab.json        原始词库
src/core/             词条、批改、会话、复习、存储与迁移
src/audio.js          语音来源与可取消播放队列
src/features/         两种背词、错词本、原录音精听、专项
src/app.js            应用状态与页面操作
src/styles.css        白天 / 黑夜 / 响应式样式
scripts/              构建、开发服务器、产物验证
tests/                回归检查
review/               旧版审查记录与冻结基线复现脚本
```

提交源文件时同时提交两个生成的 HTML。GitHub Actions 会运行 `npm run check` 并检查构建产物是否一致。

## 静态部署

本仓库为 [UniverseCA/wanglu-dictation-app](https://github.com/UniverseCA/wanglu-dictation-app)。生成的根目录 `index.html` 可直接用于 GitHub Pages 或其他静态托管。GitHub Pages 的分支和目录以仓库 Settings → Pages 实际配置为准。开发服务器不会自动推送或发布。
