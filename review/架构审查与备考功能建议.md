审查对象：本地 `wanglu-dictation-app`，包含上一轮“连播不自动换行”的修改。

结论：保留静态网页、浏览器本地保存和键盘听写的方向，先提高批改、保存与复习记录的可靠性，再建设每日复习功能。当前最值得投入的是“正确判断答案、保存完整练习、安排下一次复习”。

本轮只新增审查材料，没有继续修改业务代码。以下分清已复现问题、源码可确认的缺口和需要真实设备验证的事项。

- F5：第 6942 行排除了错词模式。错词练习答对后没有练习历史，也没有掌握状态或下次复习时间；错词只累积错误次数。

**建议调整的结构**

保留 GitHub Pages 部署。把源代码按职责拆开，发布时生成可下载的单 HTML，继续支持双击使用；单纯换成多文件 ES Modules 会改变 `file://` 下的使用条件，应在构建方案中处理。

| 模块 | 负责什么 | 应明确的边界 |
| --- | --- | --- |
| 词库与答案规则 | 稳定词条 ID、章节来源、显示文本、朗读文本、可接受答案 | 拼写别名经过核对；数据疑点有标记和变更记录 |
| 练习会话 | 题目顺序、输入、输入焦点、播放位置、模式、开始时间 | 状态保存在数据对象里，CSS 类只负责显示 |
| 批改 | 同一份输入生成一致的逐题结果 | 不在计算分数时直接累计错词；首次提交和订正结果分别保存 |
| 存储 | 草稿、历史、错词状态、备份与版本迁移 | 提交可重试且不重复记账；恢复前校验并保存旧数据 |
| 播放 | 队列、暂停/继续、重复、失败、取消 | 播放位置独立于输入行；每次播放有清晰的取消边界 |
| 页面 | 渲染状态和响应操作 | 不用 DOM 类名决定最终分数；所有动态文本安全显示 |

数据可以先继续用 localStorage，但批量写入、草稿恢复和导出应先补齐。大量历史和本地音频出现后，再考虑迁移到 IndexedDB；目前没有必须建设服务器的证据。

词条复用需要保留来源：当前 `addToWb` 仅用小写单词作 key，首次添加时固定章节。因此，同词在其他章节再出错，会累计到第一次的章节。建议区分“词库里的题目条目”和“跨章节复习的词项”，后者保留来源集合；词义不同的同形词应允许分开。

**最值得增加的备考功能，按建议顺序排列**

| 顺序 | 功能 | 建议的第一版 | 如何判断有用 |
| --- | --- | --- | --- |
| 1 | 每日到期复习 | 打开就显示今日待复习，先旧错词后新词；答错缩短间隔，跨日答对延长间隔 | 能看到昨日错词今天是否仍会错，以及到期复习完成率 |
| 2 | 分段练习与断点恢复 | 20/50/100 词或自选范围；自动保存输入、实际乱序顺序、模式和播放位置 | 刷新或关闭后恢复同一份练习；未选入本次练习的词不计错 |
| 3 | 首次成绩与订正成绩分开 | 记录首次提交、订正后成绩、重复播放次数和辅助情况 | 能区分“第一次就会”和“看答案后会”；同条件才比较趋势 |
| 4 | 可用于安排复习的错因 | 字母差异提示、单复数/词尾差异候选；“没听出/拼错/跟丢/音频失败”由用户确认 | 不把音频故障当成能力不足；可单独抽取同类问题练习 |
| 5 | 完整播放控制 | 连播不换行、独立播放进度、暂停/继续、重播当前音频词、上一词 | 打字慢时可暂停；重播不会误播光标所在的另一题 |
| 6 | 原录音精听 | 用户选择本地音频，标记片段，A–B 循环、变速、片段听写 | 能把词汇训练接到书本录音或剑雅答案句；音频与题号对齐要可手动纠正 |
| 7 | 听力专项 | 数字、日期、姓名拼写、地址、单复数、短语；进一步做句子填空与同义替换 | 按专项记录首次成绩；模考规则与日常练习规则分别设置 |
| 8 | 我的词表与错拼链 | 粘贴个人错词，保留来源；查看如 `analysit → analyst` 的历次提交 | 原始拼写和顺序保留，疑似纠正不静默改掉；可回到来源复听 |
| 9 | 简单每日计划 | 设本日词量或时长，显示新词、复习词、首次正确率和下次任务 | 学习结束知道明天练什么；先与现有备考安排衔接 |

每日复习可以先用简单、可解释的规则，例如初始采用 1、3、7、14 天作为可调整的复习节点。这是产品初始方案，不是已经证明对你最优的固定间隔。重复回忆与间隔练习有研究依据，但本工具的具体安排需要根据实际复测表现调整。[词汇回忆实验](https://pubmed.ncbi.nlm.nih.gov/18276894/)、[间隔练习研究](https://pubmed.ncbi.nlm.nih.gov/16719566/)。

练习模式允许慢速、重复播放和即时反馈；模拟测试应按选定材料设置单次播放、结束后反馈及题目字数限制。雅思官方说明听力录音播放一次，题目有多种形式，填空可能有字数限制。因此，孤立单词 TTS 的正确率不能直接当作雅思听力分数。[雅思官方听力说明](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-listening)。

英美拼写均可接受，但别名仍应绑定具体词条与题目，不能用“相似就算对”代替规范拼写判定。[Cambridge 官方 IELTS FAQ](https://www.cambridgeenglish.org/Images/269899-ielts-general-training-faqs.pdf)。
